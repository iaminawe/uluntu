    Security Contact Email Options¶

    This document provides recommendations for the security contact email that should be added to SECURITY.md and CODE_OF_CONDUCT.md.

    Recommended Options¶

    Option 1: GitHub Security Advisories (Recommended)¶

    Use GitHub's built-in security advisory feature instead of an email:

    In SECURITY.md, replace the email section with: 

    **Please use GitHub Security Advisories to report vulnerabilities:**

https://github.com/iaminawe/nelson-tech/security/advisories/new

    Pros: - ✅ Built-in to GitHub, no additional infrastructure needed - ✅ Private communication channel - ✅ Coordinated disclosure workflow - ✅ CVE assignment support - ✅ No email maintenance required - ✅ Professional and standard practice

    Cons: - ❌ Requires GitHub account to report - ❌ Less familiar to some reporters

    Option 2: Dedicated Security Email Alias¶

    Create a dedicated security email alias: - security@yourdomain.com - security@nelson-tech.com - security@kootenay-tech-community.com

    Pros: - ✅ Professional appearance - ✅ Can be forwarded to multiple team members - ✅ Familiar to security researchers - ✅ Can use PGP encryption

    Cons: - ❌ Requires email infrastructure setup - ❌ Needs monitoring and maintenance - ❌ Potential for spam

    Option 3: Project Maintainer's Email¶

    Use the primary maintainer's email: - your-email@domain.com

    Pros: - ✅ Simple and immediate - ✅ No additional setup required - ✅ Direct communication

    Cons: - ❌ Single point of contact (vacation/absence issues) - ❌ Less professional appearance - ❌ Privacy concerns (personal email exposure)

    Option 4: GitHub Issues Email¶

    Use GitHub's private reporting via email: - Contact through GitHub profile (if enabled)

    Pros: - ✅ Uses existing GitHub infrastructure - ✅ Can keep email private

    Cons: - ❌ Not standard for security reports - ❌ Less discoverable

    Recommendation¶

    Use Option 1: GitHub Security Advisories

    This is the most professional, secure, and maintainable option. It's the standard practice for open source projects on GitHub.

    How to Enable GitHub Security Advisories¶

    1. Go to: https://github.com/iaminawe/nelson-tech/settings/security_analysis
    2. Enable "Private vulnerability reporting"
    3. Update SECURITY.md to reference the advisories URL

    1. Decide which option to use

    3. Set up email alias
