    🛠️ Environment Setup¶

    Required Environment Variables¶

    Frontend (VITE_* variables)¶

    # Application
VITE_APP_URL=https://your-domain.com
VITE_ENVIRONMENT=production

# Supabase (Required)
VITE_SUPABASE_URL=https://your-project.supabase.co
VITE_SUPABASE_ANON_KEY=your-anon-key-here

# Newsletter (Required for newsletter feature)
VITE_RESEND_API_KEY=your_resend_api_key_here
VITE_FROM_EMAIL=newsletter@your-domain.com
VITE_FROM_NAME=Your Community Name

# AI Features (Optional)
VITE_OPENAI_API_KEY=your-openai-key
VITE_ANTHROPIC_API_KEY=your-anthropic-key
VITE_UNSPLASH_ACCESS_KEY=your-unsplash-key

# Analytics (Optional)
VITE_GOOGLE_ANALYTICS_ID=your-ga-id
VITE_SENTRY_DSN=your-sentry-dsn

    Backend (Supabase Configuration)¶

    # Database
POSTGRES_HOST=your-db-host
POSTGRES_PORT=5432
POSTGRES_DB=your-db-name
POSTGRES_USER=postgres
POSTGRES_PASSWORD=your-secure-password

# Supabase Auth
JWT_SECRET=your-super-secret-jwt-key-min-32-chars
JWT_EXPIRY=3600

# Email (SMTP)
SMTP_HOST=smtp.your-provider.com
SMTP_PORT=587
SMTP_USER=your-email@domain.com
SMTP_PASS=your-app-password

    Feature Flags¶

    # Enable/disable features
ENABLE_NEWSLETTER=true
ENABLE_GALLERY=true
ENABLE_MARKETPLACE=true
ENABLE_GROUPS=true
ENABLE_EVENTS=true
ENABLE_AI_EDITOR=true

    📦 Deployment Options¶

    Option 1: Netlify (Recommended for Static Sites)¶

    Setup: 1. Connect your Git repository to Netlify 2. Configure build settings: - Build command: npm run build - Publish directory: dist - Node version: 18+

    1. Add environment variables in Netlify dashboard
    2. Deploy!

    Configuration (netlify.toml already configured): 

    [build]
  command = "npm run build"
  publish = "dist"

[build.environment]
  NODE_VERSION = "18"

# Security headers and redirects already configured ✅

    Custom Domain: 

    # Add custom domain in Netlify dashboard
# Configure DNS:
# CNAME: www.your-domain.com → your-site.netlify.app
# A Record: your-domain.com → Netlify Load Balancer IP

    Option 2: Vercel¶

    Setup: 1. Install Vercel CLI: npm i -g vercel 2. Run vercel in project directory 3. Configure: - Framework Preset: Vite - Build Command: npm run build - Output Directory: dist - Install Command: npm install

    1. Add environment variables
    2. Deploy: vercel --prod

    Option 3: Docker + Self-Hosted¶

    Dockerfile (create if needed): 

    FROM node:18-alpine AS builder
WORKDIR /app
COPY package*.json ./
RUN npm ci
COPY . .
RUN npm run build

FROM nginx:alpine
COPY --from=builder /app/dist /usr/share/nginx/html
COPY nginx.conf /etc/nginx/nginx.conf
EXPOSE 80
CMD ["nginx", "-g", "daemon off;"]

    Build and Run: 

    # Build image
docker build -t nelson-tech-platform .

# Run container
docker run -d -p 80:80 \
  -e VITE_SUPABASE_URL=https://your-project.supabase.co \
  -e VITE_SUPABASE_ANON_KEY=your-key \
  nelson-tech-platform

    Option 4: Coolify (Self-Hosted PaaS)¶

    Setup: 1. Create new application in Coolify 2. Connect Git repository 3. Configure build: - Build Pack: Nixpacks (Node.js) - Build Command: npm run build - Start Command: npm run preview or use nginx 4. Add environment variables 5. Deploy

    🗄️ Database Setup (Supabase)¶

    1. Create Supabase Project¶

    # Sign up at https://supabase.com
# Create new project
# Note: Project URL and anon key

    2. Run Migrations¶

    # Install Supabase CLI
npm install -g supabase

# Link project
supabase link --project-ref your-project-ref

# Run migrations (if you have migration files)
supabase db push

    3. Configure Storage Buckets¶

    Required storage buckets: - profile-images - Public (2 MB max) - content-images - Public (10 MB max) - group-images - Public (5 MB max) - background-images - Public (5 MB max) - gallery-photos - Public (10 MB max) - marketplace-photos - Public (5 MB max) - company-logos - Public (2 MB max)

    Create via Supabase Dashboard: 1. Storage → New Bucket 2. Set bucket name 3. Configure: Public/Private, file size limits 4. Set up policies (read: public, write: authenticated)

    4. Configure Row Level Security (RLS)¶

    • Review RLS policies for all tables
    • Ensure proper access control for:
    • Members (profile visibility)
    • Groups (privacy levels)
    • Messages (conversation isolation)
    • Admin functions (role-based)

    🔒 Security Configuration¶

    Security Headers (Already Configured ✅)¶

    The following headers are configured in netlify.toml and nginx.conf:

    • X-Frame-Options: SAMEORIGIN
    • X-Content-Type-Options: nosniff
    • X-XSS-Protection: 1; mode=block
    • Referrer-Policy: strict-origin-when-cross-origin
    • Permissions-Policy: Restricts camera, microphone, geolocation
    • Strict-Transport-Security: max-age=31536000; includeSubDomains
    • Content-Security-Policy: Configured for Supabase, OpenAI, Anthropic

    XSS Protection (Already Implemented ✅)¶

    • DOMPurify sanitization in:
    • Theme customization (custom_head_html, custom_body_html)
    • Page content rendering (rich content, video embeds)
    • User-generated content

    • ✅ Development auth bypass REMOVED
    • ✅ Secure JWT configuration
    • ✅ Role-based access control (RBAC)
    • ✅ Supabase Auth with RLS

    🚀 Deployment Process¶

    Step-by-Step Deployment¶

    1. Prepare Repository¶

    # Ensure all changes are committed
git status

# Create production branch (optional)
git checkout -b production
git push origin production

    2. Configure Hosting Platform¶

    • Add environment variables
    • Set build commands
    • Configure custom domain
    • Enable HTTPS
    • Set up automatic deployments

    3. Deploy¶

    # Netlify
git push origin main  # Auto-deploys

# Vercel
vercel --prod

# Docker
docker build -t nelson-tech .
docker push your-registry/nelson-tech:latest

    4. Post-Deployment Verification¶

    • Site loads correctly
    • Authentication works
    • Database connections work
    • Image uploads work
    • Newsletter system works
    • No console errors
    • Security headers present (check with https://securityheaders.com/)
    • SSL certificate valid
    • All API endpoints responding

    🔄 Rollback Plan¶

    If deployment fails:¶

    Netlify/Vercel: 1. Go to deployment dashboard 2. Find previous successful deployment 3. Click "Publish" on that deployment

    Docker: 

    # Rollback to previous image
docker pull your-registry/nelson-tech:previous-tag
docker stop nelson-tech
docker run -d --name nelson-tech your-registry/nelson-tech:previous-tag

    Database Rollback: 

    # If migrations fail
supabase db reset --db-url your-db-url
# Re-apply working migrations

    🆘 Troubleshooting¶

    Common Issues¶

    Build Failures: 

    # Clear cache
rm -rf node_modules dist .vite
npm ci
npm run build

    Environment Variable Issues: - Ensure all VITE_* variables are prefixed correctly - Restart development server after .env changes - Verify variables in hosting platform dashboard

    Database Connection: - Check Supabase URL and keys - Verify RLS policies - Check network connectivity - Review Supabase logs

    Image Upload Issues: - Verify storage bucket exists - Check bucket permissions (RLS policies) - Verify file size limits - Check CORS configuration
