## ✨ Key Features

### 🏢 Community Features
- **Member Directory** - Professional networking with privacy controls
- **Groups** - Interest-based communities with roles and permissions
- **Events** - RSVP, calendar integration, and media galleries
- **Companies** - Company profiles with employee associations

### 💼 Professional Tools
- **Marketplace** - Buy/sell/trade with image galleries
- **Opportunities** - Job postings and volunteer work
- **Newsletter** - Campaign management with analytics
- **Messaging** - Real-time member communication

### 🎨 Enterprise Features
- **Privacy-First Onboarding** - 5-step guided wizard
- **Advanced Permissions** - Three-level role system
- **Theme System** - Complete visual customization
- **AI-Enhanced Editor** - Smart content assistance

---

## 🏗️ Technology Stack

**Frontend**: React 18 + TypeScript 5.5 + Vite 5
**State Management**: React Query + Redux Toolkit (Hybrid)
**Backend**: Supabase (PostgreSQL + Auth + Storage)
**Testing**: Jest + React Testing Library + Playwright
**Deployment**: Netlify / Vercel / Docker

## 🚀 Getting Started

### 1. Quick Setup (5 minutes)

```bash
git clone https://github.com/iaminawe/nelson-tech.git
cd nelson-tech
npm install
cp .env.example .env
npm run dev
```

**Next Steps**: See **[Quick Start Guide](Quick-Start)** for detailed setup.

Start with these essential documents:
