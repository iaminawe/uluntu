    Theme System User Guide¶

    Overview¶

    The Nelson Tech Community Platform features a comprehensive theming system that allows administrators to customize the visual appearance of the entire platform. This guide covers all aspects of the theme system, from basic usage to advanced customization.

    1. Getting Started

    Getting Started¶

    Accessing the Theme Manager¶

    1. Navigate to Admin Settings → Appearance
    2. Click on the Theme Manager tab
    3. You'll see the theme management interface with preset themes and customization options

    Quick Start¶

    1. Select a Preset Theme: Click on any of the professionally designed preset themes
    2. Preview Changes: Use the live preview to see how the theme looks
    3. Save Theme: Click "Save Theme" to apply changes platform-wide

    Theme Manager Interface¶

    Main Components¶

    1. Theme Selector Panel (Left Side)¶

    • Displays all available preset themes
    • Shows color swatches for quick visual reference
    • Highlights the currently active theme
    • Provides theme descriptions

    2. Customization Panel (Right Side)¶

    • Color Palette: Edit individual colors
    • Typography: Adjust fonts and text sizes
    • Layout: Configure spacing and borders
    • Live Preview: Real-time theme visualization

    3. Action Toolbar¶

    • 👁️ Preview Toggle: Show/hide the live preview
    • ⬆️ Import: Load a theme from a JSON file
    • ⬇️ Export: Save current theme as JSON
    • 📋 Copy CSS: Copy theme CSS variables
    • 🔄 Reset: Revert to default theme

    Preset Themes¶

    Available Themes¶

    1. Modern Blue 🔵¶

    • Best for: Corporate, professional environments
    • Characteristics: Clean, calming blue tones with excellent readability
    • Accessibility: WCAG AA compliant

    2. Dark Professional 🌙¶

    • Best for: Reduced eye strain, night usage
    • Characteristics: Sophisticated dark theme with high contrast
    • Accessibility: Optimized for low-light environments

    3. Light Minimal ⚪¶

    • Best for: Content-focused applications
    • Characteristics: Maximum whitespace, subtle grays
    • Accessibility: High readability with minimal distractions

    4. Vibrant 🎨¶

    • Best for: Creative, energetic communities
    • Characteristics: Bold orange and purple accents
    • Accessibility: Carefully balanced for visual impact

    5. Classic 📚¶

    • Best for: Traditional, professional contexts
    • Characteristics: Timeless design with serif typography
    • Accessibility: Excellent readability for long-form content

    Custom Theme Creation¶

    Step-by-Step Guide¶

    1. Start with a Preset
    2. Select a preset theme closest to your desired look

    3. Click "Edit Colors" to enable customization

    4. Customize Colors

    5. Primary Color: Main brand color (buttons, links)
    6. Secondary Color: Supporting color for less emphasis
    7. Accent Color: Highlights and call-to-actions
    8. Background Color: Main page background
    9. Surface Color: Card and panel backgrounds

    10. Text Colors: Primary and secondary text

    11. Adjust Typography

    12. Font Family: Choose from Google Fonts library
    13. Base Font Size: 14-20px recommended
    14. Font Weights: Light (300) to Black (900)
    15. Line Heights: Adjustable for optimal readability

    #### Font Selection Process 1. Click on the Font Family dropdown in Typography settings 2. Search for fonts by name or browse by category: - Sans Serif (clean, modern) - Serif (traditional, elegant) - Display (decorative, impactful) - Handwriting (personal, casual) - Monospace (technical, code) 3. Preview fonts with custom text before applying 4. Font loads automatically when selected 5. System applies fallback fonts for reliability

    1. Configure Layout
    2. Border Radius: 0-20px for rounded corners
    3. Shadow Style: None, small, medium, or large
    4. Container Width: Maximum content width

    Color Selection Tips¶

    • Contrast: Ensure text is readable against backgrounds
    • Brand Alignment: Use your organization's brand colors
    • Consistency: Limit color palette to 3-5 main colors
    • Accessibility: Check contrast warnings in real-time

    Accessibility Features¶

    Built-in Accessibility Checks¶

    The theme system automatically validates: - ✅ Text Contrast: Minimum 4.5:1 for normal text - ✅ Large Text Contrast: Minimum 3:1 for headings - ✅ Button Contrast: White text on colored backgrounds - ✅ Focus Indicators: Visible keyboard navigation

    Accessibility Warnings¶

    When a theme fails accessibility checks: 1. ⚠️ Yellow warning box appears 2. Specific issues are listed 3. Contrast ratios are displayed 4. Suggestions for improvement provided

    Keyboard Navigation¶

    • Tab: Navigate through interface elements
    • Enter/Space: Select themes or activate buttons
    • D: Quick switch device preview
    • V: Toggle preview visibility
    • Arrow Keys: Navigate theme list

    Performance Optimization¶

    Automatic Optimizations¶

    1. Theme Caching
    2. Themes cached for 1 hour
    3. Instant switching between previously used themes

    4. LocalStorage persistence

    5. Lazy Loading

    6. Theme assets loaded on demand
    7. Preview images optimized

    8. Font preloading for smooth transitions

    9. Debounced Updates

    10. Color changes batched
    11. 300ms delay prevents excessive updates
    12. Smooth real-time preview

    Best Practices¶

    • Limit Custom Fonts: Use system fonts when possible
    • Optimize Images: Keep theme previews under 100KB
    • Test Performance: Check theme switching speed
    • Monitor Cache: Clear cache if themes seem outdated

    Import/Export Themes¶

    Exporting a Theme¶

    1. Customize your theme
    2. Click the Export button (⬇️)
    3. Theme downloads as theme-[id]-[timestamp].json
    4. Share file with other administrators

    Importing a Theme¶

    1. Click the Import button (⬆️)
    2. Select a .json theme file
    3. Theme loads with "(Imported)" suffix
    4. Review and save to apply

    Theme File Format¶

    {
  "id": "custom-theme",
  "name": "My Custom Theme",
  "description": "A beautiful custom theme",
  "isDark": false,
  "colors": {
    "primary": "#3B82F6",
    "secondary": "#64748B",
    "accent": "#0EA5E9",
    "background": "#F8FAFC",
    "surface": "#FFFFFF",
    "text": "#1E293B"
  },
  "typography": {
    "fontFamily": "Inter",
    "fontSizeBase": 16
  },
  "layout": {
    "borderRadius": 8,
    "shadowStyle": "medium"
  }
}

    Troubleshooting¶

    Common Issues¶

    Theme Not Applying¶

    • Solution: Clear browser cache and reload
    • Check browser console for errors
    • Ensure you clicked "Save Theme"

    Colors Look Different¶

    • Cause: Monitor color profiles
    • Solution: Test on multiple devices
    • Use web-safe colors

    Poor Performance¶

    • Solution: Disable theme transitions temporarily
    • Clear theme cache
    • Reduce custom font usage

    Import Fails¶

    • Cause: Invalid JSON format
    • Solution: Validate JSON structure
    • Check file isn't corrupted

    Error Recovery¶

    If the theme system encounters an error: 1. Error boundary displays helpful message 2. Click "Try Again" to retry 3. Use "Reset to Default" if issues persist 4. Contact support with error details

    Developer Documentation¶

    Architecture Overview¶

    Theme System
├── Theme Presets (predefined configurations)
├── Theme Manager (UI component)
├── Theme Cache (performance layer)
├── Theme Provider (React context)
└── Accessibility Utils (validation)

    Key Components¶

    ThemeManager¶

    Main UI component for theme management - Location: /src/components/admin/settings/ThemeManager.tsx - Props: currentTheme, onThemeChange, onSave

    ThemeProvider¶

    React context providing theme to entire app - Location: /src/providers/ThemeProvider.tsx - Hooks: useTheme()

    Theme Presets¶

    Predefined theme configurations - Location: /src/lib/themes/presets.ts - Validation: WCAG compliance built-in

    Theme Cache¶

    Performance optimization layer - Location: /src/lib/services/themeCache.ts - Features: LRU eviction, localStorage persistence

    Integration Guide¶

    // Using theme in components
import { useTheme } from '@/providers/ThemeProvider';

function MyComponent() {
  const { theme, primaryColor } = useTheme();

  return (
    <div style={{ color: primaryColor }}>
      Current theme: {theme}
    </div>
  );
}

    Font System Details¶

    How Fonts Are Loaded¶

    1. Font Selection
    2. User selects a font from the FontSelector component
    3. Component displays popular fonts and allows searching

    4. Preview text can be customized for testing

    5. Dynamic Loading

    6. When a font is selected, a Google Fonts link is created
    7. Link includes weight variations (300-700)
    8. Font is loaded asynchronously to prevent blocking

    9. Font Loading API ensures font is ready before use

    10. Application

    11. Font is applied via CSS variables
    12. Body font: --theme-font-family
    13. Heading font: --theme-font-family-heading

    14. Fallback chain ensures text remains readable

    15. Persistence

    16. Font choice is saved to database
    17. Applied on page load for all users
    18. Cached in browser for performance

    Font Fallback System¶

    /* Example fallback chain */
font-family: 'Inter', system-ui, -apple-system, BlinkMacSystemFont, 
             'Segoe UI', Roboto, Oxygen, Ubuntu, Cantarell, 
             'Helvetica Neue', sans-serif;
    • Primary: Selected Google Font
    • System: Native system fonts for performance
    • Generic: Final fallback (sans-serif, serif, monospace)

    Performance Optimization¶

    1. Font Display Strategy
    2. Uses display=swap for better loading experience
    3. Text remains visible with fallback during load

    4. Smooth transition when custom font loads

    5. Caching

    6. Google Fonts are cached by browsers
    7. Popular fonts often pre-cached

    8. Reduces load time on repeat visits

    9. Weight Optimization

    10. Only requested weights are loaded (300-700)
    11. Reduces download size
    12. Synthetic bold/italic avoided

    Troubleshooting Font Issues¶

    Font Not Loading¶

    1. Check internet connection
    2. Verify Content Security Policy allows fonts.googleapis.com
    3. Check browser console for errors
    4. Try a different font to isolate issue

    Font Looks Different¶

    1. Ensure correct weights are loaded
    2. Check font rendering settings in OS
    3. Verify font supports required characters
    4. Test in different browsers

    Performance Issues¶

    1. Use popular fonts (better cached)
    2. Limit number of font weights
    3. Consider system fonts for critical text
    4. Enable font-display: swap
